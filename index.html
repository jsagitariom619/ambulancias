Almacenamiento clínico local

La base actual conserva los almacenes originales de pacientes y emergencias. Los nuevos datos se agregan a los registros existentes, sin reinicializar ni cambiar el esquema.

Base local: medsolution_ambulancia_piloto_v1 · Esquema v2.

Limitación de seguridad: IndexedDB en uso no está cifrada. El respaldo exportado sí se cifra. No existe autenticación corporativa ni la plataforma está aprobada para datos clínicos reales.

Crear respaldo cifrado

Exporta todos los almacenes locales con sus identificadores y relaciones. Cifrado AES-256-GCM; contraseña derivada con PBKDF2-SHA-256 (310 000 iteraciones) y sal aleatoria. La contraseña no se guarda y no puede recuperarse.

Restaurar respaldo

Primero valida autenticidad, integridad, esquema y claves. Añade registros ausentes; conserva los ya idénticos. Si una clave existe con otros datos, cancela toda la operación sin sobrescribir registros.

Administración de empresas y dispositivos

La integración Supabase está pendiente. No se envían datos clínicos desde este dispositivo y no hay credenciales configuradas en el repositorio.

Cuando se configure, Supabase se limitará a empresas, usuarios autorizados, activaciones y dispositivos.
